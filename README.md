# The Duck Farm

This is a small JAX exploratory project building a RL environment for the breeding of animals within a confined grid. 

The goal of the RL agent in this environment is to keep the duck population controlled within a given bound through the strategic use of food and poison. 

The ducks will evolve as time goes on, enabling them to avoid poison more easily and move more rapidly around the grid. 

# Current Feature Set
- Ducks move
- Ducks eat
